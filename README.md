# 🐍 Pastel Snake

> Even developers need a little fun.

Un juego de la culebrita con estética pastel, hecho con **HTML, CSS y JavaScript puro**: sin frameworks, sin librerías y sin paso de build.

**▶ Jugar:** https://sofiaas16.github.io/culebrita/

## Cómo se juega

- Come **♥** para sumar 1 punto y **✦** para sumar 3. La estrella desaparece si no llegas a tiempo (el anillo muestra cuánto le queda).
- Con cada bocado la culebrita va un poco más rápido.
- Pierdes si chocas con una pared o contigo misma.

| Acción | Teclado | Celular |
|---|---|---|
| Mover | Flechas o `WASD` | Deslizar sobre el tablero o ▲ ◀ ▼ ▶ |
| Pausa | `Espacio` o `P` | Botón ❚❚ |
| Reiniciar | `Enter` o `R` | Botón "Jugar de nuevo" |

El mejor puntaje se guarda en tu navegador (`localStorage`).

## Archivos

```
index.html   estructura de la página
style.css    tema "Pastel Tech" (claro/oscuro automático)
game.js      lógica del juego, sin DOM
main.js      dibujo en <canvas>, controles e interfaz
```

## Correr en local

Abre `index.html` en el navegador. No hace falta servidor.
